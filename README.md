# 峰谷节奏（peak-rhythm）

Aurabot 的独立模块：**DeepSeek 高峰时段少说话，空闲时段活跃一点**。

峰谷口径和计价插件 [`dsh-meter`](https://github.com/J-Chien/dsh-meter) 完全对齐——
按真实的峰谷计价来调整聊天频率，不是拍脑袋定时段。

## 规则

| | |
|---|---|
| **高峰** | 北京时间 **周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00** |
| **空闲** | 其余所有时间：周末整天、法定节假日整天、工作日的非高峰时段（官方半价） |
| 调休补班 | **不算高峰**——官方规则是"周一到周五减节假日"，不是"工作日" |

## 它怎么干预

只挂一个钩子 `group/decide`（群里"这条回不回"的最终决定）：

- **高峰**：本来要回 → 按「高峰保留%」压下来（默认只留 20%）
- **空闲**：本来不回 → 按「空闲插话%」插一句（默认 15%）
- **私聊**、**被 @（`mode: must`）**：一律不动

被压下来/插话时，日志会写明原因：

```
[peak-rhythm] 高峰时段，安静（工作日 9:00-12:00 高峰）
[peak-rhythm] 空闲时段，主动一点（法定节假日（2026-10-01））
```

## 参数

Aurabot 面板 → 系统 → **峰谷节奏**：

| 参数 | 默认 | 说明 |
|---|---|---|
| 启用峰谷节奏 | 开 | 关掉 = 完全回到原逻辑 |
| 高峰时保留回复（%） | 20 | 0 = 高峰完全不回（@ 和私聊除外） |
| 空闲时主动插话（%） | 15 | 0 = 不主动 |
| 高峰时段 | `9-12,14-18` | 北京时间、工作日生效；可改，如 `8-13,14-18` |

QQ 里发 `/峰谷` 随时看当前状态、参数和日历覆盖。

## 安装 / 部署

```powershell
node scripts/deploy.mjs        # 复制到 %USERPROFILE%\.dsh\plugins-data\aurabot\modules\peak-rhythm
# Aurabot 会在 3 秒内热加载（日志：模块「峰谷节奏」已启动）
```

## 验证

```powershell
npm test                       # 21 项：时间边界、节假日、门控、接线、日历对齐
node scripts/state.mjs         # 看现在算峰还是谷
node scripts/state.mjs 2026-10-01   # 看某天（会正确地判成「法定节假日」）
```

`npm test` 里有一条 **和 dsh-meter 的日历逐条对齐**的检查：
如果计价插件更新了节假日表而本仓库没跟，这条测试会直接失败（没装 dsh-meter 时自动跳过）。

## 节假日表怎么更新

国务院一般在前一年 11 月发通知。拿到通知后改 `calendar.mjs` 的 `HOLIDAYS`，
新增一年即可（`YYYY-MM-DD` 或 `YYYY-MM-DD..YYYY-MM-DD` 区间）：

```js
2027: [
  '2027-01-01..2027-01-03',
  ...
],
```

然后 `npm test`：那条对齐测试会告诉你和 `dsh-meter` 差在哪几天。
没覆盖到的年份按「普通工作日全算高峰」处理，`/峰谷` 和 `scripts/state.mjs` 都会提示。

## 已知边界

- **只认放假日，不认调休补班**：与官方规则一致（见上）。
- **时区固定 Asia/Shanghai**：DeepSeek 按北京时间计价。
- **不对私聊降频**：省钱不该省掉基本响应。

## 设计取舍

| 取舍 | 为什么 |
|---|---|
| **只认放假日，不认调休补班** | 官方规则是「周一到周五**减法定节假日**」，不是"工作日库"。调休把周末变工作日，但按这条规则不算高峰 |
| **只挂 `group/decide`，不吞消息** | 这是 Aurabot 给的"这条回不回"钩子，改它最干净；在 `message` 里吞会让日志和"她怎么没回"对不上 |
| **私聊 / 被 @ 不动** | 省钱不该省掉基本响应 |
| **纯函数 + 固定时间戳** 做测试 | 测试不能依赖"跑的时候几点、周几"，否则周一到周五绿、周末红 |
| **和 dsh-meter 对表的测试** | 计价是别人算的。它更新日历我没跟，边会红，而不是钱算错了才发现 |
| **独立仓库** | 跟表情库无关；放一起会出现"一处代码两个来源" |
